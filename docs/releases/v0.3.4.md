# GS3104T PRO Linux 配置工具 v0.3.4

修复亮度选项实际改变闪光速度的问题。

- 按原版 Windows 驱动更正灯光参数的位置：亮度、速度、方向分别写入对应字段，方向采用原厂初始值 0。
- 同时修复有线与 2.4G，命令行、JSON API 和 GTK 界面共用修正后的编码器；调用参数保持不变。
- 补充协议说明、逆向报告及回归测试，更正此前灯光实机记录的验证范围。
- README 明确说明色彩预览并不可靠，仅供示意，以键盘实际效果为准。

## 下载与安装

- `ganss-gs3104t-0.3.4-2-any.pkg.tar.zst`：Arch Linux 安装包。
- `ganss_gs3104t-0.3.4-py3-none-any.whl`：Python 包。
- `SHA256SUMS`：安装包与 Python 包的 SHA256 校验摘要。

```sh
sha256sum --check --ignore-missing SHA256SUMS
sudo pacman -U ./ganss-gs3104t-0.3.4-2-any.pkg.tar.zst
```

安装后重启配置工具，重新应用灯光设置。
