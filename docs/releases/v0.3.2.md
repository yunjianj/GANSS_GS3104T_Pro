# GS3104T PRO Linux 配置工具 v0.3.2

首次公开发布，提供命令行、JSON Lines 前端接口和 GTK 3 桌面界面。

- 自动扫描受支持的键盘，保留原始硬件名以区分有线和 2.4G 模式，按名称或 ID 操作。
- 支持灯光模式、颜色、亮度、速度，以及单键映射和整层配置；附带 20 种原厂灯效名称及逆向报告。
- 修复固件资源选取错误：使用随包官方 EXE 的 RCDATA/4000 完整 64 KiB 镜像，SHA256 `42924f581b208c23ea4818c6a4d6db59669dfb4059074b99b635a2ee13c73fed`，校验和 `0x2765`。
- 适配官方实际使用的 `20 03` 更新流程，并允许进入 ISP 后保留原 USB 身份。更新按扫描结果选择通道，不写死接口或 hidraw 节点。
- 首次提交包含脱敏的官方升级回放样例、离线测试、公开证据摘要及 Arch 打包脚本；原始抓包、其他厂商样本和完整转储留在本地。

## 下载与安装

- `ganss-gs3104t-0.3.2-1-any.pkg.tar.zst`：Arch Linux 安装包，包含桌面入口、图标和 udev 规则。
- `ganss_gs3104t-0.3.2-py3-none-any.whl`：Python 包；其他 Linux 发行版的安装及桌面依赖见仓库 README。
- `SHA256SUMS`：上述两个文件的 SHA256 校验摘要。

Arch Linux 下载后执行：

```sh
sha256sum --check --ignore-missing SHA256SUMS
sudo pacman -U ./ganss-gs3104t-0.3.2-1-any.pkg.tar.zst
```

安装后重新打开配置工具。固件升级必须使用 USB 有线模式；按键映射如未生效，请检查 Fn+Tab 是否屏蔽驱动自定义指令。

## 验证范围

81 项离线测试通过，完整官方 Windows 升级抓包与 Linux 后台任务的 1024 个数据块、有效控制参数和最终校验一致。旧版 2.4G 灯光、普通层映射及恢复默认已有实际效果确认。

Linux 完整固件刷写尚未实机验证；更新会替换固件及其配置，期间应保持供电和连接。当前仅适配已核实的 ISP `20 03 00 00`、`5A 5A` 保护状态，其他返回值在修改前停止。请勿把 Windows 抓包回放通过理解为 Linux 实机刷写已完成验证。
